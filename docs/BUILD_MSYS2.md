# Сборка SolverUNIX Kernel в MSYS2 (Windows)

Эта инструкция описывает подготовку среды MSYS2 и сборку SolverUNIX Kernel на Windows.

> **Важно:** ядро должно собираться как freestanding ELF64 для bare metal. Обычные GCC из MinGW/UCRT64 (цель `x86_64-w64-mingw32`) создают Windows-программы и **не заменяют** кросс-компилятор `x86_64-elf`.

## 1. Установите и обновите MSYS2

Скачайте MSYS2 с официального сайта: <https://www.msys2.org/>.

Откройте терминал **MSYS2 UCRT64** и обновите пакеты:

```bash
pacman -Syu
```

Если установщик попросит закрыть терминал, закройте его, снова откройте MSYS2 UCRT64 и выполните:

```bash
pacman -Su
```

Установите базовые инструменты:

```bash
pacman -S --needed base-devel git python
```

## 2. Установите кросс-компилятор x86_64-elf

Для полноценной сборки нужны программы с такими именами:

- `x86_64-elf-gcc` — компилятор C;
- `x86_64-elf-as` — ассемблер;
- `x86_64-elf-ld` — ELF-линковщик;
- `x86_64-elf-binutils` — набор инструментов Binutils.

Установите или соберите toolchain отдельно. Он должен создавать **ELF x86-64**, а не PE/COFF для Windows. Не используйте вместо него обычные `gcc`, `clang` или `x86_64-w64-mingw32-gcc` для финальной сборки ядра.

Если toolchain находится в `C:\cross\bin`, добавьте его в PATH текущего терминала MSYS2:

```bash
export PATH="/c/cross/bin:$PATH"
```

Если он установлен в другом месте, замените путь на свой. Чтобы проверить доступность инструментов:

```bash
which x86_64-elf-gcc
which x86_64-elf-as
which x86_64-elf-ld

x86_64-elf-gcc --version
x86_64-elf-as --version
x86_64-elf-ld --version
```

Все три команды `which` должны найти соответствующие программы.

## 3. Получите исходный код

```bash
git clone https://github.com/kolonfan4ikxx/SolverUNIX_Kernel.git
cd SolverUNIX_Kernel
```

## 4. Проверьте путь GCC в Makefile

В текущем `Makefile` параметр `CFLAGS` содержит путь:

```make
-B C:/cross/gcc-bin/
```

Это настройка конкретной среды разработки. Если каталог `C:\cross\gcc-bin` действительно содержит внутренние программы вашего GCC toolchain, оставьте её. Если такого каталога нет, удалите этот фрагмент `-B C:/cross/gcc-bin/` из `CFLAGS` или замените его на фактический каталог внутренних программ вашего кросс-компилятора.

Не подставляйте путь наугад: `-B` задаёт GCC префикс поиска вспомогательных программ и может повлиять на выбор компилятора и линковщика.

## 5. Соберите ядро

Из корня репозитория выполните:

```bash
make clean
make
```

Цель по умолчанию `all` собирает `solverunix.elf`, а также бинарные этапы загрузчика Kolon Kiwi в каталоге `build/boot/`.

Для проверки ELF-файла и структуры ядра выполните:

```bash
make check
```

Для создания дискового образа:

```bash
make solverunix.img
```

## 6. Запуск в QEMU (необязательно)

Для запуска требуется установленный QEMU с программой `qemu-system-x86_64`. Проверьте её наличие:

```bash
qemu-system-x86_64 --version
```

Затем запустите:

```bash
make run
```

Другие доступные цели:

| Команда | Назначение |
|---|---|
| `make run-2disk` | Запуск с двумя дисковыми образами |
| `make run-debug` | Запуск QEMU с журналом отладки `qemu.log` |
| `make clean` | Удаление результатов сборки |

Создание ISO через `make iso` дополнительно требует `grub-mkrescue` и `xorriso`; эта цель не нужна для обычной сборки ELF и запуска образа через Kolon Kiwi.

## Частые проблемы

**`x86_64-elf-gcc: command not found`**

Проверьте, что каталог с кросс-компилятором добавлен в PATH текущего окна MSYS2.

**`x86_64-elf-as: command not found` или `x86_64-elf-ld: command not found`**

Установите соответствующие инструменты Binutils для target `x86_64-elf` и проверьте PATH.

**Получается Windows EXE/PE вместо ELF**

Скорее всего, используется MinGW-компилятор. Для ядра нужен toolchain с target `x86_64-elf`. Проверить формат результата можно командой:

```bash
file solverunix.elf
```

**QEMU не найден**

Установите QEMU для Windows и добавьте каталог с `qemu-system-x86_64.exe` в PATH либо укажите его расположение при запуске.

---

Инструкция относится к текущему Makefile репозитория. По мере изменения системы сборки команды и зависимости могут обновляться.
